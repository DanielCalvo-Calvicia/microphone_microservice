> **Update 2026-11-10 (found by the Docker run, T-07.3):** `docker stop` with a `/stream` consumer connected (Brain is one) waits for Docker's 10 s grace period and is then killed (exit code 137, 10.46 s), because uvicorn's graceful shutdown waits for the open request and the cleanup never runs; without a consumer it stops in 0.69 s with exit code 0 and the cleanup logs appear. Debt, not fixed: a candidate is uvicorn's `timeout_graceful_shutdown` (close the streams after a few seconds). A real device is released by the operating system when the process dies.

> **Update 2026-11-10 (fixed):** `main_flow/http.py` passes `timeout_graceful_shutdown=GRACEFUL_SHUTDOWN_SECONDS` (5 s) to uvicorn, which now cancels the open requests after 5 s and runs the lifespan cleanup. Test first (`tests/main_flow/test_shutdown.py`, failing on the old code), 4 of 4 one-line mutations caught. Re-run in Docker with Docker's default 10 s grace period: with a `/stream` consumer connected `docker stop` took **5.69 s** and ended with exit code **0**; the log shows the stream terminated, `Application shutdown complete`, `Server stopped; releasing microphone` and `Cleanup finished`; the client's stream ended cleanly. uvicorn logs the cancelled request as an ERROR line (`Exception in ASGI application`, `CancelledError: Task cancelled, timeout graceful shutdown exceeded`): expected noise.

> **Update 2026-11-10 (T-04.2):** the cost of the default treatment on a real microphone is measured: 3.4 s of trailing silence per utterance (a reply cannot start sooner), no clipped start. A faster setting exists (smoothing factor 0.3, silence limit 1.0 s: 1.4 s) but its false-start risk with noise is untested; no default was changed (decision pending).

> **Update 2026-11-10 (T-04.2 closed):** loud non-speech noises (taps, coughs, a clap) start utterances under any treatment: on a 45 s noise recording the defaults cut 4 false utterances and the faster setting (smoothing 0.3, limit 1.0 s) 8; a higher start volume cuts them by half or more but its effect on soft speech is not measured. Debt, accepted: the wake-phrase gate in Brain drops them. The defaults stay.
