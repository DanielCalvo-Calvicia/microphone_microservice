## Resolution

*Answered 2026-11-09 (Q02-1 to Q02-3, all "Recommended"): code default `real`, `MICROPHONE_BACKEND=real|sim` (unknown value stops the start), preset `sim` in the catalogue, backend reported in the `reason` of `/available` (no `contracts` change), generated signal paced to real time, once per `/start`. Written as [ADR-007](../../decisions/ADR-007-simulated-capture-backend.md) (Accepted); PR-001 has a dated note.* (Original instruction, kept: when the maintainer answers: write each answer after `A:` in Q01, copy it here with its date, create ADR-007 (new, "A simulated capture backend") with the status `Accepted`, set PR-001's status line to `Accepted` with a dated note, and mark this task `done`.
