## Goal

A fake sound card: `SimulatedAudioCapture` (`AudioCapturePort`) and `SimulatedAudioStream` (`AudioStreamPort`) that produce mono PCM16 chunks of a fixed pattern.

## What it must do

- `open_stream(audio_format)` returns a stream at `audio_format.sample_rate` (it can "negotiate" any rate), mono, `chunk_size` frames per chunk; it never fails.
- `check_device()` returns `(True, "simulated input (MICROPHONE_BACKEND=sim)")`: the reason carries the word `simulated` so `/available` shows it.
- The stream pattern, repeating: a few chunks of low noise (amplitude about 20, so the noise-floor tracking has something to learn), a number of chunks of a 300 Hz tone at amplitude about 8000 (a phrase), then enough silent chunks (amplitude 0) to exceed `silence_limit_seconds`, then the pattern again. The pattern lengths are constants of the adapter, in chunks, not settings (unless T-02.1 says otherwise).
- It paces itself like a real device: `await asyncio.sleep(chunk_size / sample_rate)` per chunk, so the segmenter sees real-time chunks and Brain is not flooded.
- Iteration ends with `StopAsyncIteration` after `close()`; `close()` is idempotent; `on_terminated(callback)` is accepted and never fires (a simulated device does not fail).
- The first chunk logs once, through `shared_logging`, that the input is simulated (see T-02.3 for the start-up log).

## What it must not do

- Import `sounddevice`, `numpy` is allowed but not needed (`array` and `math` are enough).
- Read or write any file; log samples.
- Import anything from `contracts/tests` or another service.
- Be used unless the composition root chooses it.

## Acceptance

- Opening a stream at 16000 Hz yields chunks of `chunk_size * 2` bytes; after `close()` iteration ends.
- Fed through an `UtteranceSegmenter` with the default `InputTreatment`, the stream produces at least one utterance per pattern repetition and no utterance during pure noise.
- `tests/architecture/test_dependency_rules.py` stays green (the new package is under `infrastructure/outbound` and imports only `application`, `domain` and the standard library).
- Baseline of the tasks README section 3.

Done.
