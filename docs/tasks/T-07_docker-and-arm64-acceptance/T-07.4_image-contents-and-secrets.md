## Goal

Prove the image has no dev tools (audit problem 3) and no secret, and that the `.env` is only bind-mounted. Same method as stt's [T-03.4](../../../../stt_microservice/docs/tasks/T-03_docker-and-arm64-acceptance/T-03.4_image-contents-and-secrets.md): searches are for the **absence** of a name; print counts, never a value.

## Steps

1. `pip list` inside the image: no `pytest`, `httpx`, `ruff`, `black`, `mypy`, and (with T-06.1 built) `python-dotenv` present.
2. `ls -la /app`: no `.env`, `.env.staging`, `.env.production`, `windows`, `.git`.
3. `docker history --no-trunc` and `docker inspect` of the image and of the running container: no `.env` content, no variable that looks like a key (counts only). The container shows the `.env` as a read-only bind mount (or, until T-06.1, `--env-file`: say which).
4. `docker save <image> | tar -t`: no `.env` entry (names only).
5. The user of the process (`Config.User`): record it (the image has no `USER`, so root; a finding for `docs/security/security.md`, not a fix).

## Acceptance criteria

Steps 1 to 4 find nothing unexpected; the user is recorded.

## Result (2026-11-10)

All by counts and names, no value printed. **Dev tools:** `pip list` inside the image has no `pytest`, `httpx`, `ruff`, `black` or `mypy`; it has `python-dotenv`, `numpy`, `sounddevice`, `fastapi`, `uvicorn`, `contracts-microservice`, `shared-logging` and their dependencies (21 packages in all with pip). **Files:** `ls -A /app` of the image shows no `.env`, `.env.staging`, `.env.production`, `windows`, `.git`, `.venv` or `testclear` (the running container shows `.env` only as the mount); the image does hold `tests/`, `docs/`, `vendor/`, `libs/` and `.engram/` (the Dockerfile copies the whole tree: 1.2 MB). **Secrets:** 0 matches for `API_KEY`, `SECRET`, `TOKEN`, `PASSWORD`, `sk-` and `gsk_` in `docker history --no-trunc`, in `docker inspect` of the image and in `docker inspect` of the running container; the container's environment variables are only `GPG_KEY` (the public key id of the Python base image, not a secret), `LANG`, `PATH`, `PYTHONDONTWRITEBYTECODE`, `PYTHONUNBUFFERED`, `PYTHON_SHA256` and `PYTHON_VERSION`; the mounts are one bind, `/app/.env`, read-only. **Layers:** `docker save` has 9,953 file entries over the layers and **0** `.env*` entries other than `.env.example`. **User:** `Config.User` is empty: the process runs as root (a finding for `docs/security/security.md`, not fixed here).
