## Specification

- The preset is a plain catalogue `env` value, not a new catalogue key: no new mechanism. The value `real` in a local file wins over it (the existing layer order).
- If Q02-1 chose **no preset**, the task only documents it (T-06.5) and its acceptance reduces to the test that a local `sim` is accepted by `validate`.

## Acceptance criteria

The resolved env of a microphone in a throw-away layout has `MICROPHONE_BACKEND=sim`; with a local `real` it has `real`; `oblivion.py validate --host <machine> --config <throw-away folder>` does not warn about the variable (it is in `.env.example`); `env_inventory.py --check` passes after `--write`; the deployment suite passes.

## Verification

The targeted tests, then `scripts\env_inventory.py --check` from `deployment/`, then the whole suite in the background.
